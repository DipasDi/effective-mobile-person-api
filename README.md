# Тестовое задание для Effective Mobile

## Описание решения

Реализован сервис на Go с использованием Gin для обработки REST запросов, который:
- Обогащает данные пользователя (возраст, пол, национальность) из внешних API
- Сохраняет данные в PostgreSQL
- Предоставляет CRUD операции с пагинацией и фильтрацией

# Особенности реализации

1. **Миграции**:
   - Использовал библиотеку `golang-migrate` для управления миграциями
   - Впервые использовал миграции поэтому поначалу были сложности

2. **Архитектура**:
   - Разделил код на контроллеры, базу данных и внешние API
   - Использовал логгер zerolog логирования
   - Реализовал пагинацию и фильтрацию в GET-запросе
